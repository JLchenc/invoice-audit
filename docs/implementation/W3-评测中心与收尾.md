## 步骤

1. **评估集导入**：`data/manifest.json` 的 50 张（`document_path` + `ground_truth` 整包 + `tags=[layout, subtype]`）+ `data/kb_documents.json` 的 `qa_cases` 10 条（`document_path` 填 `"qa"` 占位、`tags=["qa"]`、ground_truth 存 `{question, expected_doc_key}`——DDL 的 NOT NULL 约束不动，语义放 tags）
2. **评测运行器**（arq 异步，PRD F8）：逐 case 跑 L1（parse_pdf）+ L2（LLM 或 parser 抽取）+ 规则回放（`run_rule_chain`，三单查 seed 的主数据表）。**评测不写 `invoice_documents`/`match_results`/`review_queue`**——评估跑 10 次也不该在业务库留 10 遍假数据
3. **指标聚合**（对齐 PRD §9.1）：

   | 指标 | 定义 | 目标（门禁） |
   | --- | --- | --- |
   | field_acc_overall | 12 字段抽对总数 / 应抽总数 | ≥ 0.95（blocking） |
   | field_acc_key | 金额×3 + 销方税号 + 发票号 五个关键字段 | ≥ 0.98（blocking） |
   | auto_pass_rate | outcome=pass 的比例 | ≥ 0.70（blocking） |
   | attribution_acc | 判定 outcome+codes 与 ground truth 完全一致 | ≥ 0.90 |
   | qa_hit_rate | qa 用例 top-5 检索命中 expected_doc_key | ≥ 0.90 |
   | avg_latency_ms / total_cost | 全链路耗时均值 / LLM 成本 | 报告值（无门禁） |

4. **门禁（变更门禁的落地）**：blocking 指标不达标 → `status='blocked'`。改 prompt（`extract_v2`）或改规则 → 重跑评测 → compare 对比上一版 → 达标才允许发布——PRD §9.3 的流程闭环
5. **收尾**：规则回滚端点（F9 补完）、dashboard 的 evalDigest、评估报告脚本、PRD §10 DoD 全项对照

### 核心概念（前端视角）

| 概念 | 前端类比 |
| --- | --- |
| **评估集（eval_cases）** | 固定的测试 fixture：输入 + 期望输出锁死，跑多少遍都不变——评测才有可比性 |
| **eval run** | CI 的一次流水线运行：同一份 fixture，不同的代码/prompt/规则版本，产出一份指标 |
| **门禁（gates）** | CI 的 required checks：blocking 指标红了就不许合并（发布），和「测试不过不许 merge」一个道理 |
| **compare** | 两次 CI 运行的指标 diff 视图：`{field, current, previous}` 一行一个指标 |
| **规则回放** | 因为 P3 是纯函数，「历史数据 + 新参数重跑」零成本——不需要真实重处理就能预演新规则的影响 |
| **评测不写业务表** | 测试不污染生产数据：e2e 跑十次，数据库里不能多十份订单 |

```python
"""评估集导入：manifest 50 张发票 + kb qa_cases 10 条 → ctrl.eval_cases。
case_key 幂等（已存在跳过）。qa 用例的 document_path 填 'qa' 占位、语义靠 tags。"""
import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent.parent))

import asyncio
import json

from sqlalchemy import select

from app.db.base import SessionLocal
from app.models.ctrl_models import EvalCase

DATA = Path(__file__).resolve().parent.parent.parent / "data"


async def main():
    manifest = json.loads((DATA / "manifest.json").read_text(encoding="utf-8"))
    kb = json.loads((DATA / "kb_documents.json").read_text(encoding="utf-8"))

    rows = []
    for inv in manifest["invoices"]:
        gt = dict(inv["ground_truth"])
        gt["expected_outcome"] = inv["expected_outcome"]
        gt["reason_codes"] = inv["reason_codes"]
        gt["review_priority"] = inv.get("review_priority")
        gt["po_number"] = inv.get("po_number")
        gt["grn_number"] = inv.get("grn_number")
        rows.append(EvalCase(
            case_key=Path(inv["file"]).stem,                 # INV-2026-0001
            document_path=inv["file"],                        # 相对 data/ 的路径
            ground_truth=gt,
            tags=[inv["layout"], inv.get("expected_subtype") or "ok"],
        ))
    for q in kb["qa_cases"]:
        rows.append(EvalCase(
            case_key=f"qa-{len(rows) + 1:02d}",
            document_path="qa",                               # 占位（DDL NOT NULL）
            ground_truth={"question": q["question"],
                          "expected_doc_key": q["expected_doc_key"],
                          "expected_points": q["expected_points"]},
            tags=["qa", q.get("purpose", "")],
        ))

    async with SessionLocal() as session:
        existing = set((await session.execute(select(EvalCase.case_key))).scalars())
        added = [r for r in rows if r.case_key not in existing]
        session.add_all(added)
        await session.commit()
        print(f"新增 {len(added)} 条（已存在 {len(existing)} 条跳过）")


if __name__ == "__main__":
    asyncio.run(main())
```

### 2) `server/app/eval/runner.py`（评测运行器）

```python
"""评测运行器：评估集全链路回放，只写 ctrl.eval_runs，不碰业务表。

与 pipeline/runner 的关系：复用同一批函数（parse_pdf / extract / run_rule_chain），
但不写 invoice_documents / match_results / review_queue——评测跑十遍，业务库零污染。
"""
from __future__ import annotations

import time
from collections import Counter
from datetime import datetime, timezone
from decimal import Decimal
from pathlib import Path

from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession

from app.core.config import get_settings
from app.core.llm_client import AsyncLLMClient
from app.core.providers import cost_cny
from app.core.security import decrypt_value
from app.knowledge.retriever import hybrid_search
from app.models.app_models import Contract, GoodsReceipt, PurchaseOrder
from app.models.ctrl_models import EvalCase, EvalRun, LlmProvider, RuleVersion
from app.pipeline.extract import (FIELD_NAMES, extract_fields_llm,
                                  extract_fields_parser)
from app.pipeline.layout import parse_pdf
from app.pipeline.rules import DEFAULT_RULES, run_rule_chain

ROOT = Path(__file__).resolve().parents[3]        # app/eval/runner.py → 项目根
DATA = ROOT / "data"

MONEY = ("amount_ex_tax", "tax_amount", "total_amount")
KEY_FIELDS = ("invoice_no", "seller_tax_no", *MONEY)

# 门禁定义（PRD §9.1 的目标值）：blocking=True 的不达标 → run.status='blocked'
GATES = [
    {"key": "field_acc_overall", "label": "字段级准确率", "threshold": 0.95, "blocking": True,
     "hint": "12 个字段的全量命中率（金额按分对齐比较）"},
    {"key": "field_acc_key", "label": "关键字段准确率", "threshold": 0.98, "blocking": True,
     "hint": "发票号/销方税号/三个金额字段。已知 C 版式样本的发票号 gt 与 PDF 不一致，此项预期红"},
    {"key": "auto_pass_rate", "label": "整单自动通过率", "threshold": 0.70, "blocking": True,
     "hint": "outcome=pass 占比（评估集 20% 是构造差异票，0.70 目标按此设计）"},
    {"key": "attribution_acc", "label": "差异归因正确率", "threshold": 0.90, "blocking": False, "hint": ""},
    {"key": "qa_hit_rate", "label": "制度问答检索命中率", "threshold": 0.90, "blocking": False, "hint": ""},
]


def _amount_eq(got: str | None, want) -> bool:
    if got is None or want is None:
        return False
    q = Decimal("0.01")
    return Decimal(got).quantize(q) == Decimal(str(want)).quantize(q)


async def _three_way_sources(session, po_number, grn_number):
    po = grn = contract = None
    if po_number:
        po = (await session.execute(select(PurchaseOrder)
              .where(PurchaseOrder.po_number == po_number))).scalars().first()
        if po:
            grn = (await session.execute(select(GoodsReceipt)
                   .where(GoodsReceipt.po_number == po.po_number))).scalars().first()
            contract = (await session.execute(select(Contract)
                        .where(Contract.seller_tax_no == po.seller_tax_no,
                               Contract.date_from <= po.order_date,
                               Contract.date_to >= po.order_date))).scalars().first()
    return po, grn, contract


async def run_eval(session: AsyncSession, eval_run_id: int) -> None:
    run = await session.get(EvalRun, eval_run_id)
    run.status = "running"
    await session.commit()
    started = time.perf_counter()

    # 当前生效的规则版本（评测与生产同一份判据）
    rules_row = (await session.execute(
        select(RuleVersion).where(RuleVersion.status == "published")
        .order_by(RuleVersion.id.desc()))).scalars().first()
    rules = dict(rules_row.rules) if rules_row else dict(DEFAULT_RULES)

    # L2 的执行器（llm 或 parser——模式记进 run.prompt_version，指标才可跨 run 比较）
    client, provider_row = None, None
    if get_settings().extractor != "parser":
        provider_row = (await session.execute(
            select(LlmProvider).where(LlmProvider.is_active.is_(True)))).scalars().first()
        if provider_row:
            client = AsyncLLMClient(
                base_url=provider_row.base_url,
                api_key=decrypt_value(provider_row.api_key_enc, get_settings().fernet_key),
                model=provider_row.model)

    cases = (await session.execute(select(EvalCase).order_by(EvalCase.id))).scalars().all()
    invoice_cases = [c for c in cases if "qa" not in (c.tags or [])]
    qa_cases = [c for c in cases if "qa" in (c.tags or [])]

    field_hit, field_total = Counter(), Counter()
    outcome_ok = auto_pass = attribution_ok = 0
    latencies: list[int] = []
    total_cost = Decimal("0")
    seen: set[str] = set()          # ⚠️ 判重依赖顺序：必须按 case id 顺序串行累加

    for case in invoice_cases:
        gt = case.ground_truth
        t0 = time.perf_counter()
        layout = parse_pdf(DATA / case.document_path)               # L1
        text = "\n".join(b.text for b in layout.blocks)
        if client:                                                   # L2
            result = await extract_fields_llm(text, client)
            total_cost += cost_cny(result.prompt_tokens, result.completion_tokens,
                                   provider_row.price_in_per_1k, provider_row.price_out_per_1k)
        else:
            result = extract_fields_parser(text)
        latencies.append(int((time.perf_counter() - t0) * 1000))

        # 字段准确率（金额按分对齐；None 只能等于 None）
        for name in FIELD_NAMES:
            got = result.fields.get(name)
            got_val = got.value if got else None
            want = gt.get(name)
            want_s = str(want) if want is not None else None
            if name in MONEY and want_s is not None:
                ok = _amount_eq(got_val, want_s)
            else:
                ok = (got_val or None) == (want_s or None)
            field_total[name] += 1
            field_hit[name] += 1 if ok else 0

        # 规则回放（fields dict 的组装与 pipeline/runner._to_rule_fields 同构）
        fields_plain = {k: (Decimal(v.value) if k in MONEY and v and v.value is not None
                            else (v.value if v else None))
                        for k, v in result.fields.items()}
        fields_plain["items"] = result.items
        confidences = {k: v.confidence for k, v in result.fields.items()}
        po, grn, contract = await _three_way_sources(session, gt.get("po_number"), gt.get("grn_number"))
        po_d = (None if po is None else {
            "po_number": po.po_number, "seller_tax_no": po.seller_tax_no,
            "amount_ex_tax": po.amount_ex_tax, "tax_amount": po.tax_amount,
            "order_date": po.order_date, "items": po.items})
        grn_d = (None if grn is None else {
            "grn_number": grn.grn_number, "po_number": grn.po_number,
            "received_qty": grn.received_qty, "receipt_date": grn.receipt_date})
        c_d = (None if contract is None else {
            "contract_no": contract.contract_no, "seller_tax_no": contract.seller_tax_no,
            "date_from": contract.date_from, "date_to": contract.date_to,
            "amount_limit": contract.amount_limit})
        outcome, _pri, diffs = run_rule_chain(fields_plain, confidences, po_d, grn_d, c_d, seen, rules)
        codes = [x.code for x in diffs]
        outcome_ok += outcome == gt.get("expected_outcome")
        auto_pass += outcome == "pass"
        attribution_ok += codes == (gt.get("reason_codes") or [])

    # qa 用例：检索 top-5 是否命中 expected_doc_key（制度问答的「引用正确」）
    qa_hits = 0
    for case in qa_cases:
        hits = await hybrid_search(session, case.ground_truth.get("question", ""), k=5)
        qa_hits += case.ground_truth.get("expected_doc_key") in {h.doc_key for h in hits}

    # 聚合写 run
    n = len(invoice_cases) or 1
    field_accuracy = {f: round(field_hit[f] / field_total[f], 4) for f in field_total}
    overall = sum(field_hit.values()) / max(sum(field_total.values()), 1)
    key_acc = (sum(field_hit[f] for f in KEY_FIELDS)
               / max(sum(field_total[f] for f in KEY_FIELDS), 1))
    run.field_accuracy = field_accuracy
    run.pass_rate = Decimal(str(round(outcome_ok / n, 4)))           # 判定正确率
    run.auto_pass_rate = Decimal(str(round(auto_pass / n, 4)))
    run.avg_latency_ms = sum(latencies) // len(latencies) if latencies else 0
    run.total_cost_cny = total_cost
    run.metrics = {
        "field_acc_overall": round(overall, 4),
        "field_acc_key": round(key_acc, 4),
        "auto_pass_rate": round(auto_pass / n, 4),
        "attribution_acc": round(attribution_ok / n, 4),
        "qa_hit_rate": round(qa_hits / max(len(qa_cases), 1), 4),
    }
    blocking_fail = [g["key"] for g in GATES
                     if g["blocking"] and run.metrics.get(g["key"], 0) < g["threshold"]]
    run.status = "blocked" if blocking_fail else "completed"
    run.finished_at = datetime.now(timezone.utc)
    run.name = f"{run.name} · {int((time.perf_counter() - started))}s · {'🚫' if blocking_fail else '✅'}"
    await session.commit()
```

> 注意 `run.status` 的第三种值：PRD DDL 注释写的是 running/completed/failed——这里加了 **blocked**（门禁未过）。门禁红了不是「失败崩了」（failed 留给异常），是「跑完了但不许发布」。

```python
from app.eval.runner import GATES, KEY_FIELDS
from app.pipeline.extract import EXTRACT_PROMPT_VERSION

_METRIC_ROWS = [   # metrics dict → 前端 EvalMetric[]（value 一律 ×100 展示百分制）
    ("field_acc_overall", "字段级准确率", "%", 95),
    ("field_acc_key", "关键字段准确率", "%", 98),
    ("auto_pass_rate", "整单自动通过率", "%", 70),

def _eval_payload(run: EvalRun, prev: EvalRun | None) -> dict:
    m = run.metrics or {}
    finished = run.status in ("completed", "blocked")
    blocking_fail = sum(1 for g in GATES if g["blocking"]
                        and m.get(g["key"], 0) < g["threshold"]) if finished else None
    status = ("running" if run.status == "running"
              else "blocked" if run.status == "blocked"
              else "failed" if run.status == "failed"
              else "passed")
    duration = (int((run.finished_at - run.created_at).total_seconds())
                if run.finished_at else 0)
    fa = run.field_accuracy or {}
    return {
        "run": {"runNo": f"EVAL-{run.id:03d}",
                "promptVersion": run.prompt_version or "-",
                "ruleVersion": run.rule_version or "-",
                "samples": run.total_cases, "durationSec": duration,
                "status": status, "finishedAt": fmt_dt(run.finished_at)},
        "metrics": [
            {"key": k, "label": label, "value": round(float(m.get(k, 0)) * 100, 2),
             "unit": unit, "target": target,
             "passed": bool(m.get(k, 0) >= target / 100) if finished else False,
             "hint": next((g["hint"] for g in GATES if g["key"] == k), "")}
            for k, label, unit, target in _METRIC_ROWS
        ] + ( [{"key": "avg_latency", "label": "平均耗时", "value": run.avg_latency_ms or 0,
                "unit": "ms", "passed": True},
               {"key": "total_cost", "label": "总成本", "value": float(run.total_cost_cny or 0),
                "unit": "¥", "passed": True}] if finished else []),
        "fieldAccuracy": [{"field": f, "accuracy": fa.get(f, 0),
                           "target": 0.98 if f in KEY_FIELDS else 0.95,
                           "samples": run.total_cases} for f in fa],
        "compare": ([{"field": f, "current": fa.get(f, 0),
                      "previous": (prev.field_accuracy or {}).get(f, 0)} for f in fa]
                    if prev and prev.field_accuracy else []),
        "gates": [{"key": g["key"], "label": g["label"],
                   "actual": round(float(m.get(g["key"], 0)) * 100, 2),
                   "threshold": g["threshold"] * 100,
                   "passed": bool(m.get(g["key"], 0) >= g["threshold"]) if finished else False,
                   "blocking": g["blocking"], "hint": g["hint"]} for g in GATES],
    }


@router.post("/evals/rerun")
async def rerun_eval(request: Request, session: AsyncSession = Depends(get_session),
                     user: str = Depends(get_current_user)):
    """一键评测（异步）：建 run → 入队 → 立即返回 running 态 payload。"""
    total = (await session.execute(select(func.count())
              .select_from(EvalCase))).scalar_one()
    if total == 0:
        raise HTTPException(400, "评估集为空，先跑 scripts/seed_eval_cases.py")
    rules_row = (await session.execute(
        select(RuleVersion).where(RuleVersion.status == "published")
        .order_by(RuleVersion.id.desc()))).scalars().first()
    extractor = get_settings().extractor
    run = EvalRun(name=f"评测 {datetime.now():%m-%d %H:%M}",
                  prompt_version=(EXTRACT_PROMPT_VERSION if extractor != "parser"
                                  else "parser-offline"),
                  rule_version=rules_row.version if rules_row else "v0-default",
                  total_cases=total, status="running")
    session.add(run)
    await session.commit()
```

```python
        m = run.metrics or {}

        ]
```

### W3-F8 常见坑（踩之前先读）

- **❶ 重复票的 seen 必须按顺序累加**：评测循环里 `seen` 是跨 case 的局部变量，必须串行、按 `EvalCase.id`（= 导入时的 manifest 顺序）。用 `asyncio.gather` 并发跑评测会破坏判重语义——0046~0050 会全部误判 pass，`attribution_acc` 直接掉 10%。
- **❷ parser 模式下 field_acc_key 预期红**：C 版式 9 张的 `invoice_no`（PDF 20 位 vs gt 8 位）+ B/C 部分缺 `invoice_code`，关键字段准确率上不了 98%。这是**评测中心的价值演示**：指标看板把数据集的已知瑕疵量化出来了。两条路二选一：按 `tags` 过滤 C 版式单独统计（报告里加一列「剔除已知瑕疵」），或修 `generate_samples.py` 让 gt 与 PDF 一致后重新生成（seed 固定可复现）。
- **❸ 评测与生产的指标跨模式不可比**：parser 的字段准确率是「正则对文本层的命中率」，LLM 的才是「模型抽取质量」——`prompt_version` 列记了 `parser-offline` / `extract_v1`，compare 对比时先看这一列是不是同模式。
- **job_timeout**：`run_eval` 是单个 arq job 跑全部 case，LLM 模式 3~8 分钟——默认 300s 会超时，`WorkerSettings.job_timeout = 600`。想更稳可以按 case 分片入队（每 10 张一个 job，汇总逻辑放最后一个 job），v1 不必。
- **评测的 LLM 成本不写 `llm_usage`**：`total_cost_cny` 记在 `eval_runs` 上，避免评测流量把「生产成本看板」（dashboard 的 monthCost）打高。成本归因按 run 类型分账——这也是个可以讲的取舍。
- **`eval_runs.status` 多了 `blocked`**：DDL 注释里没有它（draft 时只有 running/completed/failed）。跑出的值超注释范围不是错误——列是 TEXT，语义由代码定义；面试被问就说「门禁红是完成态的一种，不是失败态」。
