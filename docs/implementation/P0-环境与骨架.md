## 步骤

1. **建 Python 环境**（uv 一把梭，比 pip+venv 快一个数量级，且全程不用激活）：
   ```powershell
   cd D:\project\agent\invoice-audit
   uv venv                                  # 建 .venv
   uv pip install "fastapi[standard]" "sqlalchemy[asyncio]>=2.0" alembic asyncpg redis arq openai pydantic-settings python-multipart cryptography pdfplumber pypdfium2 pytest pytest-asyncio httpx ruff
   ```
   > **`sqlalchemy[asyncio]` 不是 `sqlalchemy`**：async 引擎（`create_async_engine` / `AsyncSession`）底层依赖 `greenlet`，只有装了 `[asyncio]` 这个 extra 才会把 `greenlet` 一起带上。只装 `sqlalchemy` 会在启动时报 `ImportError: the greenlet library is required`——这就是很多人第一次跑 `uvicorn` 直接崩的原因。已经装错的话补一句：`uv pip install greenlet` 即可，不用重装。
   ```
   之后所有命令统一 `uv run xxx`（自动用 .venv，**永远不用 activate**）：`uv run uvicorn app.main:app --reload`、`uv run pytest`、`uv run alembic upgrade head`。
   安装完建议 `uv lock` 生成 `uv.lock` 锁死版本——评测指标可复现的前提。`uv.lock` 和 `.venv/` 一起进 .gitignore 时注意：**lock 要入库，venv 不入库**。

   > **依赖已经用 pip 装好了？** 跳过本步，直接进第 2 步。uv 只是安装器，不改变 .venv 里已有的包；命令暂时用 `.venv\Scripts\python.exe -m xxx`（或 `.venv\Scripts\Activate.ps1` 激活）。等 P1 落 `pyproject.toml` 时再 `uv lock` 补可复现性，届时零重装。

## 常见坑

- Windows 下 `pgvector/pgvector:pg16` 镜像拉取慢属正常，`docker pull` 放后台
- `.env` 里 `DATABASE_URL=postgresql+asyncpg://invoice:invoice_dev@127.0.0.1:5432/invoice_audit`（注意是 `postgresql+asyncpg://`，不是裸 `postgresql://`）
- **Windows 连不上 Docker 映射端口、表现为「挂起到超时」而不是「拒绝连接」**：十有八九是 IPv6——`localhost` 优先解析成 `::1`，而 Docker Desktop 的端口转发只听 IPv4。症状：`docker ps` 显示 healthy、容器内 `redis-cli ping` 返回 PONG，但宿主机 Python 连不上。确诊：`Test-NetConnection localhost -Port 6380` 若警告 `TCP connect to (::1 : 6380) failed` 即中招。解法：`.env` 主机一律写 `127.0.0.1`，改完重启所有读 `.env` 的进程。

### Python 新人须知（踩坑前先读）

- **`__init__.py` 是空的**：Python 用「文件夹里有没有 `__init__.py`」来判断它能不能被 `import`。空文件就行，不用写内容。删了会 `ModuleNotFoundError`。
- **绝对导入 `from app.core.config import`**：`app` 是包名、`core` 是子包。前提是你在 `server/` 目录下启动 uvicorn（`uvicorn app.main:app`），`server` 才会被加进 Python 的搜索路径。
- **`app.main:app` 怎么念**：`app.main` 是「包 `app` 里的模块 `main.py`」，冒号后面的 `app` 是那个文件里 `app = FastAPI(...)` 这个变量名。所以**入口文件必须放在 `app/` 里面**（即 `server/app/main.py`），放 `server/` 根目录就得写成 `uvicorn main:app`——两种写法只差路径，但为了和 PRD 附录 A 的骨架一致，本项目统一用 `app/main.py`。类比前端：`app.main:app` ≈ 从 `app/main.ts` 里 `export` 出来的那个 `app` 实例。
- **`async` / `await`**：Python 的异步语法，和 JS 的 `async/await` 一模一样。`async def` 是异步函数，`await` 等待异步结果。
- **依赖注入 `get_session`**：这是个「生成器函数」（`yield`），FastAPI 会在每个请求里自动调它拿一个数据库会话，请求结束自动关闭。等价于 React 里 Provider 自动给组件注入 context。
- **`pydantic_settings.BaseSettings`**：自动把环境变量/`.env` 映射成带类型的对象，改值不用动代码。类比前端的 `zod` schema 校验 + 读取 `import.meta.env`。

### `server/app/main.py`（应用入口 + 健康检查）

> ⚠️ **位置别搞错**：这个文件放在 **`app/` 包里面**（`server/app/main.py`），不是 `server/` 根目录。因为 `app/` 里有 `__init__.py`，它是包，入口属于包里的一员；启动命令相应是 `uvicorn app.main:app`。若你之前建成了 `server/main.py`（`uvicorn main:app` 也能跑），二选一即可，但**全项目统一用 `app/main.py`**（对齐 PRD 附录 A）。

```python
# 标准库：asynccontextmanager 用来定义「应用启动/关闭时做什么」的生命周期钩子
from contextlib import asynccontextmanager

# redis 的异步客户端（Python 连 Redis 的官方库，asyncio 版本）
import redis.asyncio as aioredis
# FastAPI 本体 + 跨域中间件
from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware
# SQLAlchemy 的 SQL 构造工具，这里只用来发一句 "SELECT 1" 探活
from sqlalchemy import text

# 下面三行导入我们自己写的模块（相对导入，见上方「新人须知」）
from app.api import admin, biz
from app.core.config import get_settings
from app.db.base import engine

# 读取配置（其实就是读 .env 那一堆地址）
settings = get_settings()


# 生命周期：应用启动时建一个 Redis 连接挂到 app 上；关闭时释放
# 类比前端：应用挂载时初始化一个全局 WebSocket 连接
@asynccontextmanager
async def lifespan(app: FastAPI):
    app.state.redis = aioredis.from_url(settings.redis_url, decode_responses=True)
    yield  # ← 应用正常运行期间停在这里
    await app.state.redis.aclose()
    await engine.dispose()  # 关闭数据库连接池


# 创建 FastAPI 实例（相当于 createApp），并绑定上面那个生命周期
app = FastAPI(
    title="发票智审 InvoiceAudit API",
    description="应付核算数字员工（工号 AP-001）· api/biz 业务面 + api/admin 控制面",
    version="0.1.0",
    lifespan=lifespan,
)

# 跨域：允许前端开发服务器（Vite 默认 5173 端口）访问本后端
app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:5173"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

# 把两个路由模块挂上来（顺序无所谓）
app.include_router(biz.router)
app.include_router(admin.router)


# 健康检查端点：前端/部署平台用来判断服务是不是活着
@app.get("/healthz")
async def healthz():
    checks = {}  # 装两个组件的检测结果
    # 1) 数据库探活：连上去发 SELECT 1，能返回就说明 DB 通
    try:
        async with engine.connect() as conn:
            await conn.execute(text("SELECT 1"))
        checks["db"] = True
    except Exception as exc:
        checks["db"] = False
        checks["db_error"] = str(exc)  # 把错误原因也返回，方便排查
    # 2) Redis 探活：ping 一下
    try:
        await app.state.redis.ping()
        checks["redis"] = True
    except Exception as exc:
        checks["redis"] = False
        checks["redis_error"] = str(exc)
    # 两个都 True 才算 ok，否则 degraded（降级）
    ok = bool(checks.get("db")) and bool(checks.get("redis"))
    return {"status": "ok" if ok else "degraded", **checks}
```

### `server/app/core/config.py`（配置中心）

```python
# lru_cache：把函数结果缓存住，多次调用只初始化一次（单例效果）
from functools import lru_cache

# pydantic_settings：把环境变量/`.env` 自动转成有类型的对象
from pydantic_settings import BaseSettings, SettingsConfigDict


class Settings(BaseSettings):
    # model_config：告诉它去读 .env 文件，编码 utf-8，多出来的变量忽略
    model_config = SettingsConfigDict(
        env_file=".env", env_file_encoding="utf-8", extra="ignore"
    )

    # 这三个字段就是 .env 里的值。类型标注 = 强类型约束。
    # 默认值兜底：即使 .env 没配也能起服务，方便本地快速试跑。
    database_url: str = "postgresql+asyncpg://invoice:invoice_dev@localhost:5432/invoice_audit"
    redis_url: str = "redis://localhost:6380/0"
    fernet_key: str = ""


# get_settings() 全局唯一取配置入口；lru_cache 保证只解析一次
@lru_cache
def get_settings() -> Settings:
    return Settings()
```

### `server/app/core/security.py`（Key 加密）

```python
"""Fernet 对称加密：LLM provider Key 等敏感配置，落库前加密、用时解密。"""


# cryptography 是 Python 加密标准库；Fernet 是其中「简单安全的对称加密」
from cryptography.fernet import Fernet


# 把字符串密钥变成 Fernet 对象。key 必须是字节，这里做了 str→bytes 兜底
def get_fernet(key: str) -> Fernet:
    return Fernet(key.encode() if isinstance(key, str) else key)


# 加密：明文 → 密文（存库用）
def encrypt_value(plaintext: str, key: str) -> str:
    return get_fernet(key).encrypt(plaintext.encode()).decode()


# 解密：密文 → 明文（用时取出来）
def decrypt_value(token: str, key: str) -> str:
    return get_fernet(key).decrypt(token.encode()).decode()
```

### `server/app/db/base.py`（数据库基座）

```python
# SQLAlchemy 异步三件套：
#  AsyncSession   —— 一次数据库会话（类比 Prisma 的一次 client.xxx 调用上下文）
#  async_sessionmaker —— 会话工厂，生产 AsyncSession
#  create_async_engine —— 引擎，管理连接池（类比 PrismaClient 实例）
from sqlalchemy.ext.asyncio import AsyncSession, async_sessionmaker, create_async_engine
from sqlalchemy.orm import DeclarativeBase

from app.core.config import get_settings

_settings = get_settings()


# DeclarativeBase：ORM 模型类的基类。所有表模型都继承它。
# 全库只用这一个 Base，靠表定义里的 schema="app"/"ctrl" 区分两套表。
class Base(DeclarativeBase):
    pass


# 创建引擎：pool_pre_ping=True 每次取连接先探活，断线自动重连；echo=False 不打印 SQL
engine = create_async_engine(_settings.database_url, pool_pre_ping=True, echo=False)
# 会话工厂（expire_on_commit=False 避免提交后对象被清空，前端思维：数据取出来还能读）
SessionLocal = async_sessionmaker(engine, class_=AsyncSession, expire_on_commit=False)


# 依赖注入函数：FastAPI 路由用 `Depends(get_session)` 就能拿到一个会话
# async with 保证请求结束自动关闭连接，不会泄漏
async def get_session():
    async with SessionLocal() as session:
        yield session
```

### 启动与验收

```powershell
cd D:\project\agent\invoice-audit\server
uv run uvicorn app.main:app --reload --port 8000   # 推荐：走工程环境，依赖由 pyproject.toml + uv.lock 统一管理
# 另开终端：
curl.exe http://localhost:8000/healthz   # 期望 {"status":"ok","db":true,"redis":true}
```

> **命令里的 `app.main:app` 是什么**：`app.main` = 包 `app` 下的模块 `main.py`（即 `server/app/main.py`），冒号后的 `app` = 该文件里的 `app = FastAPI(...)` 变量。所以入口文件在 `app/` 包内时用 `app.main:app`；如果你手工建成了 `server/main.py`，则要写 `main:app`（且必须 `cd server` 再启动）。**本项目统一 `app/main.py` + `app.main:app`**。

> **跑起来之后 curl 没输出 / 卡住**：先看 uvicorn 那侧日志。如果看到 `ImportError: the greenlet library is required`，说明这个解释器缺 `greenlet`（`sqlalchemy` 装了但没装 `[asyncio]` extra）。补装：`uv pip install greenlet`（或 `sqlalchemy[asyncio]`）。装好后**必须重启 uvicorn**（`--reload` 只在代码改动时重启，不重载已装依赖）。
>
> **`uv run` 现在可用了**：项目根已建好 `pyproject.toml` + `uv.lock`，`uv run` 直接吃这个工程环境（`.venv` 在项目根），依赖齐全不再丢 `greenlet`。只要在项目里（任意子目录）跑 `uv run <命令>`，uv 会自动找到根的 `pyproject.toml`。改了 `pyproject.toml` 依赖后记得 `uv lock && uv sync` 同步。若换机器重装，直接 `uv sync` 一条命令还原整个环境（这就是 uv.lock 的意义）。

常见错：`db:false` → compose 没起或 `.env` 端口错；`redis:false` → `.env` 里 redis 端口写成 6379 了，改 **6380**。返回体里带 `db_error` / `redis_error` 时，直接看那个字段就是根因（密码错 / 端口错 / 库没起）。
